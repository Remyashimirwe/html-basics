# Exercise 1: Personal Profile Page

Create a file named `profile.html`.

## Requirements
Build a page with:

- your name in blue using `<span>`
- an important sentence using `<strong>`
- an emphasized word using `<em>`
- a highlighted word using `<mark>`
- examples of `<u>`, `<del>`, and `<ins>`
- a small note using `<small>`
- an ordered list of your daily routine
- an unordered list of your favorite foods
- a link to YouTube
- a navigation menu with:
  - Home
  - Courses
  - Contact

## CSS Task
Use the following ideas:
- wrap the content in a `.container`
- style the navigation bar with dark background and white links
- make the name blue
- make the highlighted word stand out
- add spacing between sections

## Optional Challenge
Add a **My Goals** section with:
- one highlighted goal
- one emphasized goal
- one strong goal
