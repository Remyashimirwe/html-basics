
### **Question:**  
Write a Python function called `reverse_words(sentence)` that takes a string and returns a new string where **each word is reversed**, but the **word order stays the same**.

### **Requirements:**  
- Preserve the original spacing between words  
- Do not use Python’s built‑in `[::-1]` slicing to reverse the entire sentence at once  
- You *may* use slicing to reverse individual words  
- Input will always be a string  

### **Example:**  
```python
reverse_words("Future Focus Academy")  
# Output: "erutuF sucoF ymedacA"
```
