# 📝 HTML Practice Exercise: My Profile Page

## ✅ Task

Create a new HTML file called:

``` text
profile.html
```

Inside it, build a page that contains the following:

------------------------------------------------------------------------

## 1️⃣ Introduction Section

Write a paragraph that says:

> Hello, my name is your name.

Your name must be colored blue using `<span>`.

------------------------------------------------------------------------

## 2️⃣ Important Message

Write this sentence:

> Learning HTML is very important for web development.

Make **"very important"** bold using `<strong>`.

------------------------------------------------------------------------

## 3️⃣ Emphasis Sentence

Write:

> I really enjoy coding.

Emphasize the word **"really"** using `<em>`.

------------------------------------------------------------------------

## 4️⃣ Highlight a Word

Write:

> My favorite language is Python.

Highlight **"Python"** using `<mark>`.

------------------------------------------------------------------------

## 5️⃣ Text Decoration Practice

Create 3 sentences:

-   Underlined word using `<u>`
-   Deleted word using `<del>`
-   Inserted word using `<ins>`

------------------------------------------------------------------------

## 6️⃣ Small Text Note

Add a note at the bottom:

> This page was created for practice.

Make it small using `<small>`.

------------------------------------------------------------------------

## 7️⃣ Ordered List: Daily Routine

Create a numbered list with 3 steps:

1.  Wake up\
2.  Study\
3.  Practice coding

Use `<ol>`.

------------------------------------------------------------------------

## 8️⃣ Unordered List: Favorite Foods

Create a bullet list of 3 foods you like using `<ul>`.

Example:

-   Pizza\
-   Rice\
-   Fruits

------------------------------------------------------------------------

## 9️⃣ Add a Link

Add a link that says:

> Visit YouTube

It should open:

``` text
https://youtube.com
```

------------------------------------------------------------------------

## 🔟 Navigation Menu

Create a simple navigation bar like this:

-   Home\
-   Courses\
-   Contact

Use `<nav>` with `<ul>` and `<a>`.

------------------------------------------------------------------------

## ⭐ Extra Challenge (Optional)

Add a new section called **My Goals** and include:

-   One highlighted goal\
-   One emphasized goal\
-   One strong goal

------------------------------------------------------------------------

Happy Coding! 🚀
## register.html — Student Registration Form
Requirements:

Use:
```html
<form>, <label>, <input>, <select>, <textarea>, <fieldset>, <legend>, <button>
```
Fields:

Full Name (text)

Email (email)

Password

Date of Birth (date)

Gender (radio buttons)

Course (dropdown)

Hobbies (checkboxes)

Upload Photo (file)

Short Bio (textarea)

Submit & Reset buttons

Tasks:

Group related inputs using 
```
<fieldset>
```

Make required fields mandatory.

Use placeholders and default values.
